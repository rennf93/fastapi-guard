# Auto-ban (threshold=5): by this point the suspicious-activity hits from the XSS/SQLi/path-traversal/command-injection sections above have almost certainly already crossed auto_ban_threshold=5 and 127.0.0.1 is banned for the life of the server process. Every command below (and any retry of the sections above) will return "IP has been banned" (403) regardless of payload until the process is restarted. That IS the auto-ban feature working, not a bug in this file.
